本ポリシーは、Discord Bot「`<Bot の名前>`」（以下「本 Bot」）が扱う情報について説明します。本 Bot は、運営者と運営者が許可したサーバーでのみ動作します。

## 1. 取得・保存する情報

| 情報 | 取得する場面 | 保存期間 |
| --- | --- | --- |
| `/talk` の質問文、オプション（Web 検索の有無、履歴の期間）、実行日時 | `/talk` を実行したとき | 既定 30 日 |
| AI の回答、参照した Web ページの URL とタイトル、ナレッジ資料を参照したかどうかと AI に渡した資料の ID と名前、処理状態 | 回答を作成したとき | 既定 30 日 |
| 実行者の Discord ユーザー ID とユーザー名、サーバー ID、チャンネル ID、回答のメッセージ ID | 上記に付随して | 既定 30 日 |
| Web チャットの会話（質問、AI の回答、参照した Web ページの URL とタイトル、AI に渡したナレッジ資料の ID と名前、「Web検索」「ナレッジ」の指定、処理状態、日時）、会話の名前、会話したサーバーの ID、あなたの Discord ユーザー ID | Web チャットを使ったとき | 会話の最終更新から既定 30 日（いつでもご自身で削除できます） |
| サーバーの利用設定（利用を許可したロールの ID、設定したサーバー管理者のユーザー ID、日時） | サーバー管理者が `/config` または Web 管理画面でロールを設定したとき | 設定を外すか、Discord でロールが削除されるまで（本 Bot がサーバーから外された場合は「6. 本 Bot がサーバーから外されたとき」） |
| ナレッジ資料（登録したファイルから取り出した本文、ファイル名と資料名、サイズ、登録日時、登録した人の Discord ユーザー ID と表示名）と、本文を分割した断片・検索用のベクトル | サーバーの「ナレッジ管理」権限を持つ人が Web 管理画面で資料を登録したとき | 資料が削除されるまで（サーバーのナレッジ管理者が削除するか、本 Bot がサーバーから外されて猶予期間が過ぎるまで） |
| Web 管理画面のログイン情報（Discord のユーザー ID と表示名、参加しているサーバーのうち本 Bot の利用が許可されたサーバーの ID と名前、ログイン日時） | Web 管理画面に Discord でログインしたとき | ログインから 7 日（ログアウトすると直ちに削除） |
| 削除の記録（Discord ユーザー ID、削除した日時） | ご自身でデータを削除したとき、または運営者が削除のご依頼に対応したとき | 40 日（「5. ご自身のデータの確認と削除」） |
| チャンネルの過去の投稿（本文、投稿者のユーザー名とユーザー ID、日時） | `/talk` の実行時に、指定された期間（既定 15 分、最大 7 日。その中の直近 100 件まで）分を取得 | **保存しません**（回答の作成にだけ使います） |

本 Bot は、Discord から取得した投稿を AI モデルの学習には使いません。

### ナレッジ資料について

- 資料は、そのサーバーで「ナレッジ管理」権限を持つ人が Web 管理画面から登録します。登録したファイルそのものは保存せず、取り出した本文（文字だけ）を保存します。
- 資料の内容は、そのサーバーで `/talk` を使った人への回答の参考として AI に渡され、回答（チャンネルに公開されます）に引用されることがあります。回答の末尾には、AI に渡した資料の名前が表示されます。
- 資料は、そのサーバーのナレッジ管理者が Web 管理画面で削除するまで保存します。削除すると、本文・断片・検索用のベクトルもすべて削除します（バックアップには「4. バックアップ」の期間残ります）。本 Bot がサーバーから外された場合は、猶予期間の後に自動で削除します（「6. 本 Bot がサーバーから外されたとき」）。

### Web 管理画面について

- ログインには Discord の認可（OAuth2）を使い、ユーザー ID・名前と参加しているサーバーの一覧だけを読み取ります。読み取りに使った Discord のアクセストークンは直後に無効化（revoke）し、保存しません。
- ログインの状態は Cookie で管理します。使う Cookie は、ログイン中であることを示すセッション Cookie（7 日間）と、ログイン処理中だけ使う一時的な Cookie（10 分間）の 2 つだけで、どちらもランダムな値です。サーバーにはセッションの値そのものではなく、そのハッシュ値だけを保存します。広告・アクセス解析のための Cookie や外部サービスの読み込みは使いません。
- 画面に表示する権限を確認するため、本 Bot の権限で Discord から、ログインした方のそのサーバーでのロールと、サーバーのロールの一覧を取得します（最大 5 分間、メモリ上にだけ保持します）。

### Web チャットについて

- Web チャットは、本 Bot の利用を許可されたサーバーで利用ロールを持つ人が、Web 画面から AI と会話する機能です。会話は、ログインしたご本人だけが Web 画面で見られます（サーバーの管理者や他の利用者には見えません）。
- 回答を作るため、質問と、同じ会話の過去のやり取り（新しいものから最大 20 件）を AI に渡します。「Web検索」を選ぶと検索語とページの URL が、「ナレッジ」を選ぶと質問文が、それぞれ下の「第三者への提供」の提供先に送られます。Web チャットは Discord のチャンネルの投稿を読みません。
- 会話は、最後に更新されてから既定 30 日（運営者の設定）で自動的に削除します。会話の一覧からいつでもご自身で削除でき、削除するとその会話のメッセージもすべて削除します（バックアップには「4. バックアップ」の期間残ります）。
- 1 日に送れるメッセージ数の上限を確認するため、直近 24 時間の送信時刻をメモリ上に保持します（本 Bot の再起動で消えます）。

## 2. 第三者への提供

回答の作成のため、次の情報を外部のサービスへ送ります。

| 提供先 | 送る情報 | 目的・備考 |
| --- | --- | --- |
| Ollama Cloud（Ollama, Inc.、主に米国。欧州・シンガポールで処理される場合があります） | 質問文、取得したチャンネルの投稿（投稿者のユーザー名とユーザー ID を含む）、同じチャンネルの過去の `/talk` の質問（他の利用者のものを含む。ユーザー名とユーザー ID 付き）、Web チャットの同じ会話の過去の質問と回答、Web 検索の結果、ナレッジ資料の抜粋と資料名 | AI の回答の作成。提供元は、送られたデータを保存・学習に使わないと公表しています |
| 埋め込み（検索用のベクトル）を作るプロバイダー。運営者が設定したもの（`<Google（Gemini API）/ OpenAI / Ollama のうち使うもの>`） | ナレッジ資料の本文の断片と資料名（登録時）、`/talk` と Web チャットの質問文（ナレッジ資料を検索するとき） | 資料の検索。Gemini API は課金を有効にした有料枠で使います（Google は、有料枠で送られた内容をサービスの改善に使わないと公表しています）。OpenAI は、API で送られたデータを既定では学習に使わないと公表しています |
| Ollama の Web 検索・ページ取得 API | 検索語、取得するページの URL | `/talk` で `web_search:true` を指定したとき、Web チャットで「Web検索」を選んだときだけ |

法令に基づく場合を除き、これ以外の第三者には提供しません。

## 3. 安全管理

- データベースを置くサーバーのディスクは暗号化されています（AES-256）。バックアップも暗号化して保存します。
- ログには、質問文・回答・投稿の本文・認証情報（トークン・Cookie を含む）を記録しません。
- Web 管理画面は HTTPS でのみ提供します。
- データベースは外部のネットワークから接続できません。

## 4. バックアップ

障害に備えて、データベースの暗号化バックアップを取っています。バックアップは**最長 35 日**で削除されます。ご自身で削除したデータや削除依頼を受けて消したデータも、この期間はバックアップに残る場合があります。バックアップから復元したときは、削除の記録（「5. ご自身のデータの確認と削除」）をもとに、削除を適用し直します。

## 5. ご自身のデータの確認と削除

本 Bot が保存しているご自身のデータは、いつでもご自身で確認・削除できます。サーバーでの権限（利用ロールなど）は必要ありません。

- **Discord**: 本 Bot がいるサーバーで `/privacy show` を実行すると件数を、`/privacy delete` を実行すると削除の確認を表示します（どちらもご本人にだけ表示されます）。確認のボタン（10 分間有効。押せるのはコマンドを実行したご本人だけです）を押すと削除します。
- **Web 画面**: ログインして、画面上部の「あなたのデータ」を開きます。件数を確認し、確認の手順を経て削除できます。

削除の内容は次のとおりです（すべてのサーバーについて削除します）。

| データ | 削除の内容 |
| --- | --- |
| `/talk` の質問と回答の記録（回答のメッセージ ID の記録を含む） | 削除します。回答を作成中のものだけは残るので、回答が終わってから、もう一度削除してください |
| Web チャットの会話とメッセージ | 削除します。回答を作成中だった場合は、作成を止めます |
| Web 画面のログイン情報 | 削除します（すべての端末でログアウトされます） |
| ナレッジ資料とサーバーの利用設定に記録された、登録者・設定者としてのあなたの Discord ユーザー ID と表示名 | ID と表示名だけを消します。資料と設定そのものはサーバーのものなので残ります |

- チャンネルに投稿された本 Bot の回答のメッセージは Discord に残ります。ご自身の投稿の削除は、Discord でご自身で行ってください。
- 削除したデータはバックアップに最長 35 日残ります。バックアップから復元した場合にも削除し直せるよう、**削除したユーザー ID と日時だけ**を 40 日間記録し、その後は自動で消します。復元したときは、記録した日時までに作られたデータを削除し直します（その後に本 Bot を使って作られたデータは残します）。
- ナレッジ資料そのものはサーバーのものなので、資料の削除はそのサーバーのナレッジ管理者にご依頼ください。資料にご自身の個人情報が含まれている場合や、Discord・Web 画面を使えずご自身で削除できない場合は、連絡先へご依頼ください。Discord のユーザー ID で対象を特定し、速やかに削除します。

## 6. 本 Bot がサーバーから外されたとき

本 Bot がサーバーから外された（キックされた、サーバーが削除された）場合、そのサーバーに関するデータ（`/talk` の記録、Web チャットの会話、ナレッジ資料とその断片・ベクトル、利用設定）を、外された日から **`<猶予日数（既定 14）>` 日**の猶予期間の後に自動で削除します。猶予期間中に本 Bot が再び招待された場合は削除せず、そのまま使えます。削除したデータも、バックアップには「4. バックアップ」の期間残ります。

## 7. 変更

本ポリシーを変更したときは、版と制定日を更新して、このページで公開します。
