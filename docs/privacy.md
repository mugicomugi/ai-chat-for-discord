本ポリシーは、Discord Bot「`<Bot の名前>`」（以下「本 Bot」）が扱う情報について説明します。本 Bot は、運営者と運営者が許可したサーバーでのみ動作します。

## 1. 取得・保存する情報

| 情報 | 取得する場面 | 保存期間 |
| --- | --- | --- |
| `/talk` の質問文、オプション（Web 検索の有無、履歴の期間）、実行日時 | `/talk` を実行したとき | 既定 30 日 |
| AI の回答、参照した Web ページの URL とタイトル、ナレッジ資料を参照したかどうかと AI に渡した資料の ID と名前、処理状態 | 回答を作成したとき | 既定 30 日 |
| 実行者の Discord ユーザー ID とユーザー名、サーバー ID、チャンネル ID、回答のメッセージ ID | 上記に付随して | 既定 30 日 |
| サーバーの利用設定（利用を許可したロールの ID、設定したサーバー管理者のユーザー ID、日時） | サーバー管理者が `/config` または Web 管理画面でロールを設定したとき | 設定を外すか、Discord でロールが削除されるまで |
| ナレッジ資料（登録したファイルから取り出した本文、ファイル名と資料名、サイズ、登録日時、登録した人の Discord ユーザー ID と表示名）と、本文を分割した断片・検索用のベクトル | サーバーの「ナレッジ管理」権限を持つ人が Web 管理画面で資料を登録したとき | 資料が削除されるまで（サーバーのナレッジ管理者が削除するか、本 Bot がサーバーから外された後に運営者が削除するまで） |
| Web 管理画面のログイン情報（Discord のユーザー ID と表示名、参加しているサーバーのうち本 Bot の利用が許可されたサーバーの ID と名前、ログイン日時） | Web 管理画面に Discord でログインしたとき | ログインから 7 日（ログアウトすると直ちに削除） |
| チャンネルの過去の投稿（本文、投稿者のユーザー名とユーザー ID、日時） | `/talk` の実行時に、指定された期間（既定 15 分、最大 7 日。その中の直近 100 件まで）分を取得 | **保存しません**（回答の作成にだけ使います） |

本 Bot は、Discord から取得した投稿を AI モデルの学習には使いません。

### ナレッジ資料について

- 資料は、そのサーバーで「ナレッジ管理」権限を持つ人が Web 管理画面から登録します。登録したファイルそのものは保存せず、取り出した本文（文字だけ）を保存します。
- 資料の内容は、そのサーバーで `/talk` を使った人への回答の参考として AI に渡され、回答（チャンネルに公開されます）に引用されることがあります。回答の末尾には、AI に渡した資料の名前が表示されます。
- 資料は、そのサーバーのナレッジ管理者が Web 管理画面で削除するまで保存します。削除すると、本文・断片・検索用のベクトルもすべて削除します（バックアップには「4. バックアップ」の期間残ります）。

### Web 管理画面について

- ログインには Discord の認可（OAuth2）を使い、ユーザー ID・名前と参加しているサーバーの一覧だけを読み取ります。読み取りに使った Discord のアクセストークンは直後に無効化（revoke）し、保存しません。
- ログインの状態は Cookie で管理します。使う Cookie は、ログイン中であることを示すセッション Cookie（7 日間）と、ログイン処理中だけ使う一時的な Cookie（10 分間）の 2 つだけで、どちらもランダムな値です。サーバーにはセッションの値そのものではなく、そのハッシュ値だけを保存します。広告・アクセス解析のための Cookie や外部サービスの読み込みは使いません。
- 画面に表示する権限を確認するため、本 Bot の権限で Discord から、ログインした方のそのサーバーでのロールと、サーバーのロールの一覧を取得します（最大 5 分間、メモリ上にだけ保持します）。

## 2. 第三者への提供

回答の作成のため、次の情報を外部のサービスへ送ります。

| 提供先 | 送る情報 | 目的・備考 |
| --- | --- | --- |
| Ollama Cloud（Ollama, Inc.、主に米国。欧州・シンガポールで処理される場合があります） | 質問文、取得したチャンネルの投稿（投稿者のユーザー名とユーザー ID を含む）、同じチャンネルの過去の `/talk` の質問（他の利用者のものを含む。ユーザー名とユーザー ID 付き）、Web 検索の結果、ナレッジ資料の抜粋と資料名 | AI の回答の作成。提供元は、送られたデータを保存・学習に使わないと公表しています |
| 埋め込み（検索用のベクトル）を作るプロバイダー。運営者が設定したもの（`<Google（Gemini API）/ OpenAI / Ollama のうち使うもの>`） | ナレッジ資料の本文の断片と資料名（登録時）、`/talk` の質問文（ナレッジ資料を検索するとき） | 資料の検索。Gemini API は課金を有効にした有料枠で使います（Google は、有料枠で送られた内容をサービスの改善に使わないと公表しています）。OpenAI は、API で送られたデータを既定では学習に使わないと公表しています |
| Ollama の Web 検索・ページ取得 API | 検索語、取得するページの URL | `web_search:true` を指定したときだけ |

法令に基づく場合を除き、これ以外の第三者には提供しません。

## 3. 安全管理

- データベースを置くサーバーのディスクは暗号化されています（AES-256）。バックアップも暗号化して保存します。
- ログには、質問文・回答・投稿の本文・認証情報（トークン・Cookie を含む）を記録しません。
- Web 管理画面は HTTPS でのみ提供します。
- データベースは外部のネットワークから接続できません。

## 4. バックアップ

障害に備えて、データベースの暗号化バックアップを取っています。バックアップは**最長 35 日**で削除されます。削除依頼を受けて消したデータも、この期間はバックアップに残る場合があります。バックアップから復元したときは、削除依頼の内容を適用し直します。

## 5. 削除の依頼

ご自身のデータ（`/talk` の質問と回答の記録、Web 管理画面のログイン情報、ナレッジ資料に記録された登録者の ID と表示名）の削除は、連絡先へご依頼ください。ナレッジ資料そのものはサーバーのものなので、資料の削除はそのサーバーのナレッジ管理者にご依頼ください（資料にご自身の個人情報が含まれている場合は、運営者にもご連絡ください）。Discord のユーザー ID で対象を特定し、速やかに削除します。削除した記録は台帳に控え、バックアップから復元した場合にも削除し直します。Web 管理画面のログイン情報は、ご自身でログアウトしても削除されます。

サーバーから本 Bot が外された場合、そのサーバーに関するデータは一定の猶予期間の後に削除します。

## 6. 変更

本ポリシーを変更したときは、版と制定日を更新して、このページで公開します。
